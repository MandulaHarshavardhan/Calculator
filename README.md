# Calculator – Web Application

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. This project performs basic mathematical operations through a clean and user-friendly interface.

## Features
- Addition, subtraction, multiplication, and division.
- Interactive buttons for entering numbers and operators.
- Clear (AC) functionality to reset calculations.
- Responsive and visually appealing user interface.
- Real-time input handling using JavaScript.

## Technologies Used
- **HTML5** – Structure of the calculator.
- **CSS3** – Styling, layout, and visual design.
- **JavaScript** – Calculation logic and interactive functionality.

## Learning Outcomes
- Improved understanding of JavaScript fundamentals.
- Practised DOM manipulation and event handling.
- Learned to connect HTML, CSS, and JavaScript.
- Gained hands-on experience building an interactive web application.

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
